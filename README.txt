# DONARBUSTIN — Web personal

Abre `index.html` en tu navegador para ver la web.

Para poner tus redes reales:
1. Abre `index.html`.
2. Busca cada tarjeta de red.
3. Cambia `href="#"` por el enlace de tu perfil.
4. Cambia `@tu_usuario` por tu usuario.

La web es responsive y funciona en móvil y ordenador.
