SESCAM — prototipo privado para Windows

INICIO
1. Descomprime SESCAM-Windows.zip.
2. Abre SESCAM.html con Microsoft Edge, Chrome o Firefox.
3. No necesita instalación ni conexión a internet para sus funciones básicas.

FUNCIONES
- Fichas de pacientes de prueba
- Formularios de solicitud de ambulancia (no transmite avisos)
- Informes hospitalarios en borrador
- Borradores de recetas (no oficiales)
- Formularios personalizados
- Lista de documentos, descarga editable en HTML e impresión/Guardar como PDF
- Exportación e importación de copias de seguridad JSON

IMPORTANTE
Este es un prototipo independiente y no oficial, sin conexión con el SESCAM ni con servicios sanitarios.
Los datos se guardan en el almacenamiento local del navegador y NO están cifrados por esta aplicación.
No introduzcas datos reales, identificativos o médicos. No es adecuado para uso clínico real ni para emitir recetas oficiales, activar ambulancias o enviar informes a hospitales.
Para uso real se necesitaría revisión profesional, seguridad robusta, control de acceso, cifrado, copias seguras y cumplimiento normativo.
